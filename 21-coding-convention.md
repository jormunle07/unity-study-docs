# 21. Coding Convention

## Quy ước đặt tên

- Class: PascalCase
- Method: PascalCase
- Variable: camelCase

## Ví dụ

### Private field

```c#
private int hp;
```

### SerializeField

```c#
[SerializeField]
private float speed;
```

## Ghi nhớ

- Không nên dùng public nếu không thật sự cần thiết.
