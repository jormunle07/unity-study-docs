# 3. Giao diện Unity

## Các cửa sổ quan trọng

- Hierarchy: Danh sách các object trong Scene.
- Inspector: Hiển thị và chỉnh sửa Component của object đang chọn.
- Scene View: Nơi bạn thiết kế và chỉnh sửa level.
- Game View: Xem trước giao diện game khi chạy.
- Project: Quản lý toàn bộ Assets.
- Console: Hiển thị lỗi, warning và thông báo runtime.
- Package Manager: Quản lý các package được cài thêm.
