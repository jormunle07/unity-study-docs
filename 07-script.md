# 7. Script

[⬅ Quay lại](06-prefab.md) | [Tiếp theo ➡](08-c-co-ban.md)

## Khái niệm

Script là component được viết bằng C# để điều khiển hành vi của GameObject.

## Ví dụ

```c#
public class PlayerController : MonoBehaviour
{
}
```

## Ghi nhớ

- Script được attach lên GameObject để hoạt động.
- Một script thường chịu trách nhiệm cho một chức năng nhất định.
